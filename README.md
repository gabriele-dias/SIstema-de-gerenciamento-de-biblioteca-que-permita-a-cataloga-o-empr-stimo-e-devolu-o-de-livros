# Sistema de Gerenciamento de Biblioteca

Projeto desenvolvido em Python como atividade acadêmica da graduação em Ciência de Dados.

O objetivo é aplicar conceitos de lógica de programação, Programação Orientada a Objetos (POO), modularização de código e boas práticas de desenvolvimento de software.

## Funcionalidades

- Cadastro de livros
- Cadastro de usuários
- Empréstimo de livros
- Devolução de livros
- Consulta de livros por título, autor ou ano
- Relatórios de livros e usuários
- Tratamento de erros e exceções

## Tecnologias

- Python
- Programação Orientada a Objetos (POO)
- Git
- GitHub

## Objetivos de Aprendizagem

- Desenvolver a lógica de programação
- Praticar leitura e interpretação de código Python
- Aplicar conceitos de POO
- Organizar código de forma modular
- Utilizar versionamento de código com Git e GitHub
- Introduzir práticas básicas de CI/CD

## Fluxo Git

Desenvolvimento realizado através de branches de features seguindo o padrão:

feature/nome-da-feature
